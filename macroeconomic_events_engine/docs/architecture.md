# Architecture Overview

## Components
- **Acquisition**: Data collection from sources
- **Processing/Normalization**: Data cleaning and standardization
- **Classification**: Data categorization
- **Warehouse**: Persistent storage
- **Publication**: NDIP integration

## Data Flow
Source -> Acquisition -> Processing -> Classification -> Warehouse -> Publication -> NDIP

## Integration
- DAR: Runtime orchestration
- NDIP: Data publication
- Warehouse: Persistent storage
